### 🎯 2. Purpose of the Project
The purpose of this project is to help common people generate legal documents like Rent Agreement, Affidavit etc., without needing a lawyer. It uses AI to generate accurate documents quickly.

### ✨ 3. Use / Benefits
*   Saves money and time for users.
*   Easy to use for non-legal persons.
*   Provides legally accurate templates.
*   Useful for students, small business and public.

### ⚙️ 4. Project Execution / Working Process
1. User opens the website
2. User selects document type (Ex: Rental Agreement)
3. User enters basic details (Name, Address, etc.)
4. AI generates the legal document automatically
5. User can download the document as PDF

### 🖥️ 5. Final Output
Our final output is a downloadable legal PDF document.
