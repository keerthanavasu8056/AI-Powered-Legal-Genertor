#### 3. Purpose of the Project
The purpose of this project is to help common people and small businesses generate legal documents like Rental Agreements and Affidavits easily without a lawyer. Our AI creates accurate documents instantly.

#### 4. Use / Benefits of the Project
*   Saves money and time for users.
*   Very easy to use for non-legal persons.
*   Provides legally accurate templates.
*   Useful for students, small business and public.

#### 5. Project Execution / Working Process
1.  User opens the website
2.  User selects document type (Ex: Rental Agreement)
3.  User enters basic details (Name, Address, etc.)
4.  AI generates the legal document automatically
5.  User can download the document as PDF

#### 6. Final Output
Our final output is a downloadable legal PDF document. User can download and print it.
